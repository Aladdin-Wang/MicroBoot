# 串口与 Modbus

## 串口助手

“仪表盘 → 串口助手”用于独立 UART/USB 串口，不等同于 MKLink 探针的控制端口。选择端口、波特率和数据格式后再打开，关闭页面任务时释放端口。

适合文本协议、二进制帧收发和持续日志。发送二进制数据时明确使用十六进制，不要把文本 `01 03` 当作字节 `0x01 0x03`。

## Modbus RTU

推荐流程：

1. 选择独立 RS485 串口并设置波特率、校验位和停止位；
2. 扫描前确认站号范围，避免对现场总线造成额外负载；
3. 读取少量寄存器验证字节序和地址偏移；
4. 确认点表后再轮询或生成 Dashboard；
5. 写线圈或保持寄存器前说明目标值和影响。

## 资源互斥

同一个 COM 口不能同时被串口助手、Modbus、其他串口软件或另一个 MKLink 进程占用。遇到“访问被拒绝”时先关闭占用者；不要通过反复拔插掩盖资源未释放的问题。

## 使用 AI

> 列出串口并只读扫描 Modbus 站号 1–10；报告站点和参数，不写寄存器。
