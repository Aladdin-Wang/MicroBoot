# VOFA+ 数据可视化

MKLink 可以通过 SWD 采集目标 RAM 变量，再输出为 VOFA+ 可识别的数据流，不占用目标 MCU 的业务串口。它适合已有 VOFA+ 工作流的曲线观察；需要按符号名和结构体成员调试时，优先使用 [SuperWatch](superwatch.md)。

## 使用 Web GUI

1. 在“配置”中加载 AXF/ELF 并连接 MKLink；
2. 打开“仪表盘 → VOFA”；
3. 添加变量地址、类型和名称；
4. 设置合理采样周期；
5. 启动采集并观察实际采样率、丢样和缓冲状态；
6. 需要时暂停显示、缩放或导出 CSV。

当前版本的仪表盘统一使用 RTT View、SuperWatch 和 VOFA 兼容采集组件；截图以实际页面显示的组件为准。

## 使用外部 VOFA+

旧固件工作流可通过下载器虚拟串口发送 `vofa.send(...)`，再由 VOFA+ 打开相同虚拟串口。该方式属于下载器内部 PikaPython API，参数和固件版本有关；新用户优先使用 Web GUI，避免手工抄地址。

## 数据要求

- 地址必须位于目标 SRAM；
- 类型必须与实际变量一致；
- 非 4 字节变量应按固件要求对齐，避免数据撕裂；
- 高采样率不等于有效带宽，应观察实际采样率和丢样计数；
- ELF 和目标固件必须匹配。

## 成功判据

- 曲线名称、类型和单位清晰；
- 静态变量读值与调试器或一次性读取一致；
- 采集没有持续丢样；
- 观察结果能与 RTT、业务输入或寄存器状态对齐。

## 使用 AI

> 采集给定、反馈和输出三条曲线十秒，报告实际采样率、丢样和阶跃响应。
