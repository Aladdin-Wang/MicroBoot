# 安全边界与排障

## 操作分级

| 操作 | 默认策略 |
|---|---|
| 读取工程、ELF、MAP | 可直接执行 |
| 读取 RAM、寄存器、RTT | 说明范围后执行 |
| 持续采样 | 说明时长、频率和保存位置 |
| 编译 | 可执行，但不自动等同于烧录授权 |
| 烧录、擦除、复位 | 先说明目标、方式和影响 |
| 写 RAM、写寄存器 | 明确地址、类型、原值和回读验证 |

## 常见问题

### AI 找不到 Skill

确认安装的是完整目录并重启 AI 客户端。旧会话不会自动重新读取更新后的 Skill。

### 找不到 `mklink` 模块

在包含 `pyproject.toml` 的源码目录重新执行：

```powershell
python -m pip install -e ".[gui,mcp]"
```

### Web GUI 只有启动页

启动页不是 Web GUI。检查协议注册、GUI/MCP 依赖、`gui/dist` 和后台健康状态，直到页面底部出现“后端正常 · 实际端口”。

### 找不到 MKLink

检查 USB 数据线、目标供电和设备管理器，关闭占用 MKLink 或其虚拟串口的 IDE、串口工具和旧后台进程。

### 变量值明显错误

确认 ELF 与芯片中固件来自同一次构建，检查芯片型号、优化级别、变量是否被优化掉，以及地址是否位于实际 SRAM。

### AI 与 GUI 抢占设备

查看 GUI 的 owner 提示，正常停止 RTT、SystemView、SuperWatch 或烧录作业，再进行资源交接。不要同时从两个入口操作同一探针。
