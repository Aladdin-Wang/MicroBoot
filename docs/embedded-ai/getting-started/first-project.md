# 第一次接入自己的工程

不用先整理一长串工具参数。告诉 AI **工程位置、板上芯片型号和要解决的问题**，就可以开始。

> 工程在 E:\Projects\motor，接的是 STM32F103RET6。帮我检查工程配置，编译并下载，再确认主任务在运行。

如果工程里有 BootLoader、参数区或外接 Flash，一起说明哪些内容需要保留。板上芯片型号以实物为准，工程文件夹的名字不一定准确。

## 先把板子连好

将 MKLink 与电脑、开发板连接，按板卡接口确认调试线和地线。STM32 示例走 SWD，HPM 示例走 JTAG；目标板自带电源时，避免再接一路供电输出。

网页操作可看[连接硬件与配置工程](../../mklink/getting-started/project-config.md)。

## AI 会从工程中找什么

AI 会核对实际芯片、当前构建目标、固件位置和下载地址，并找到与固件配套的符号文件。如果有多个构建目标或型号冲突，先选清楚再下载。

| 你手里有什么 | 可以怎样开始 |
| --- | --- |
| 完整工程 | 让 AI 使用现有工具链编译、下载，并检查程序运行 |
| 只有 BIN / HEX | 提供准确芯片型号；BIN 还要确认镜像基址，再做下载校验 |
| 还想按名字看变量或定位源码 | 提供与固件同次构建的 AXF / ELF 和工程源码 |

**变量符号不需要你手动查地址。** MKLink 内置符号解析，正常使用不需要另装 readelf；编译工程仍需要项目原有的编译器或 SDK。

## 第一次成功后，继续提问题

> 把这几个变量画出来，让我看看有没有抖动。

或者：

> 给板子发个 help，看看现在支持哪些调试命令。

工程信息可以复用；换板、换构建目标或重新编译后，让 AI 核对变化即可。
