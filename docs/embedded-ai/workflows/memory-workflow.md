# 变量不对？从名字查到板上数据

看到数值异常，先确认读到的是什么。MKLink 可以按符号查变量，也可以读取原始内存和外设状态，不必把旧文档里的地址抄进新工程。

> 找到这个变量，看看当前值、类型和初始化是不是对的。

## 看一个数，还是看一段变化？

| 你想知道什么 | 用什么看 |
| --- | --- |
| 温度、计数或参数现在是多少 | 按变量名读取当前值 |
| 数据有没有抖动、多久变化一次 | SuperWatch 连续曲线 |
| 数组、接收缓冲区里装了什么 | 数组快照或 Memory |
| DMA、GPIO、定时器处在什么状态 | 芯片外设目录或对应寄存器 |

按名字查变量，需要与板上固件匹配的 AXF/ELF。浮点数、有符号整数和数组要按各自类型解释；值看起来离谱时，先检查符号是否过期。

## 查缓冲区内容

> 看一下接收缓冲区，确认数据长度和内容有没有变化。

在 **Memory** 填入 AI 找到的地址与长度，点击读取。对一段数组，也可以在 **SuperWatch** 选择数组父项，按元素索引查看分布。

## 查外设有没有工作

> 看看 DMA 的传输计数和缓冲区还变不变，帮我判断采集为什么停了。

在 **SuperWatch → 芯片外设** 选择准确型号后，可查看可用的寄存器和位字段。目录取决于已安装的芯片描述；没有的项由 AI 对照该型号资料检查，不套用其他芯片。

外设轮询可能漏掉短脉冲，某些寄存器读取也会改变状态。观察 GPIO 慢变化可以用曲线；判断高速边沿或精确时序，应配合示波器或逻辑分析仪。
