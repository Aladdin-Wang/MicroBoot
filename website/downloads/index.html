01 / AI SKILL

完整 Skill 下载

把完整工具接入 AI 开发环境，不只是一份 SKILL.md。

安装与更新 · 三步开始
  1. 校验 SHA-256，解压完整 *-Skill.zip（不使用 Source code ZIP 代替），按包内 SKILL.md 和安装说明安装到当前 AI 客户端的用户级 Skill 目录，同时安装运行依赖。
  2. 让 AI 完成依赖检查、Skill 自检和 MKLink 自检；打开 Web GUI，确认“后端正常”，然后开启新会话。
  3. 更新前结束烧录和采集，保留工程配置。让 AI 检查新版及更新说明，确认后更新完整 Skill 和依赖，重启 AI 客户端 / MCP 后开启新会话验证。桌面应用与 AI Skill 分别安装。
