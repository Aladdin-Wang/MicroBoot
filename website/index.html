从调试台到生产工位

遇到问题，工具就在手边。

01 / FLASH

改完代码，下载验证。

从工程编译到烧录校验，接着检查程序是否真的运行。

 02 / OFFLINE

离开电脑，也能烧录。

把固件和下载任务准备好，带到工位按键执行。

 03 / RTT

命令行，不用另接串口。

在 RTT View 看日志、发送命令，直接与板上程序交互。

 04 / MEMORY & FAULT

程序异常，查看现场。

读内存、查寄存器，结合工程符号把异常定位到源码。

 05 / SUPERWATCH

采到数据，也读懂时间。

从符号选变量、查看曲线与采样间隔，把目标变化和界面刷新分开分析。
